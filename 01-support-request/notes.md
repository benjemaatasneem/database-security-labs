# Notes – Projet 1
## Séance 1 – 18/11/2026 : installation
- J'ai installé MySQL Server 8.4.13 et MySQL Workbench 26.10.0.
- MySQL est un serveur de base de données, et Workbench est une fenêtre (un client) qui permet de parler au serveur.
- Le champ Port sert à renseigner le bon numéro du service, pour accéder au bon service. Pour MySQL, c'est 3306.
- Test réussi : SELECT VERSION(); → 8.4.13
- Localhost désigne l’ordinateur sur lequel je suis en ce moment : ça peut être mon Mac ou un autre ordinateur. C’est pour signifier la machine sur laquelle je me trouve.
- Root est le super-admin : il a tous les droits et peut définir les règles d’accès des autres comptes. Si quelqu’un vole le mot de passe root, il aura tous les droits : il pourra tout modifier, tout voler et accéder à tout.
